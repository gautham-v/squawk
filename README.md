# squawk

Local dictation for macOS. Hold fn, talk, let go: the words land in whatever has focus. Built for
talking to Claude Code in a terminal: spoken file names become `@mentions` and the repo's jargon
comes out spelled the way the repo spells it. Meetings are recorded as two tracks and transcribed
as they happen.

Everything runs on your Mac with NVIDIA's Parakeet TDT 0.6B v3. No account, no API keys, no
telemetry. The network is used once, to download the model.

Work in progress. See [SPEC.md](SPEC.md) for the design.
